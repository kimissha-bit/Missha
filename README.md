# Missha — 안전한 모의매매 MVP

이 프로젝트는 **실제 주문을 전혀 보내지 않는** 교육용 모의매매 프로그램입니다. API 키, 증권 계좌 정보, 실시간 주문 연결이 없습니다.

## 이 MVP가 하는 일

1. CSV 가격 데이터를 읽습니다.
2. 단기/장기 이동평균 교차로 매수·매도 신호를 만듭니다.
3. 가상 현금으로만 주문을 체결합니다.
4. 종목별 최대 투자금과 손실 한도를 적용합니다.
5. 거래 내역과 최종 잔고를 CSV로 남깁니다.

> 과거 수익률은 미래 성과를 보장하지 않습니다. 이 코드는 투자 조언이나 실제 주문 시스템이 아닙니다.

## 실행

Python 3.10 이상과 별도 패키지 없이 실행됩니다.

```bash
python src/paper_trader.py --prices data/sample_prices.csv --output output
```

실행 후 아래 파일이 생깁니다.

- `output/trades.csv`: 가상 체결 내역
- `output/summary.csv`: 최종 잔고와 수익률 요약

## 가격 파일 형식

```csv
date,close
2026-01-02,100.50
```

날짜 오름차순의 `date`, `close` 두 열이 필요합니다.

## 안전 규칙

- 주문은 `PaperBroker` 안에서만 처리되어 외부 증권사에 전송되지 않습니다.
- 기본값: 초기 현금 10,000, 종목 최대 투자금 1,000, 최대 손실률 5%.
- 손실 한도에 도달하면 새 매수를 멈춥니다.
- 예제는 단일 가격 시계열만 사용합니다.
